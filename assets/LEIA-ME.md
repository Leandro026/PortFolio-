# Pasta assets

| Arquivo | Onde aparece |
|---|---|
| `portrait.webp` | Foto do topo do site (sem fundo) |
| `curriculo-leandro-pelegrini.pdf` | Botões de currículo (baixa como "Curriculo Leandro Pelegrini.pdf") |
| `substation-revista.pdf` | Botões da revista (baixa como "substation revista.pdf") |
| `kanubis-1.webp`, `kanubis-2.webp` | Kanubis (símbolo e banner, passam automaticamente) |
| `substation-capa.webp`, `substation-01.webp` a `substation-06.webp` | SubStation (capa e páginas da revista) |
| `principe-cruel.webp`, `principe-cruel-completa.webp` | O Príncipe Cruel (capa e capa completa) |
| `spider-punk.webp` | Spider-Punk |

Para um novo projeto: salve as imagens aqui e adicione um bloco na lista `projetos` do `index.html`.
